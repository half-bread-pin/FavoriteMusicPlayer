# 音乐文件夹详细说明（哪个文件夹对应什么音乐）

所有音乐都放在游戏目录的 `BepInEx\plugins\FavoriteMusicPlayer\` 下（本机为 `E:\ETF\BepInEx\plugins\FavoriteMusicPlayer\`）。
把音频文件直接丢进对应文件夹即可，**无需改任何配置**；每个文件夹放多少首都行，游戏会随机选择。

## 总对照表

| 文件夹 | 对应的游戏内容 | 触发时机与播放方式 |
|---|---|---|
| `CustomMenuMusic\sounds\` | 主菜单背景音乐 | 主菜单循环播放，按歌单长度配置（默认凑够 60 分钟）随机排列 |
| `Soundtrack\default_soundtrack\` | 局内环境音乐（通用池） | 进图后随机抽曲凑够歌单长度（默认 50 分钟）依次播放 |
| `Soundtrack\map_specific_soundtrack\<地图名>\` | 对应地图的专属环境音乐 | 只在该地图进图时按配置参与抽曲 |
| `Soundtrack\combat_music\` | 战斗音乐 | 进入战斗状态后循环，战斗结束后淡出；每次战斗随机换一首 |
| `Soundtrack\spawn_music\` | 出生音乐 | 每次进战局出生时随机播一首（放多首则每局随机） |
| `DeathMusic\` | 死亡音乐 | 角色死亡结算界面播放（游戏内 `ArenaLose` 音效槽位） |
| `ExtractMusic\` | 撤离成功音乐 | 撤离成功结算界面播放（游戏内 `ArenaWin` 音效槽位） |
| `UISounds\QuestCompleted\` | 任务完成音效 | 任务完成弹窗 |
| `UISounds\QuestFailed\` | 任务失败音效 | 任务失败弹窗 |
| `UISounds\QuestFinished\` | 任务全部完成音效 | 任务整条完成 |
| `UISounds\QuestStarted\` | 接受任务音效 | 接取任务 |
| `UISounds\QuestSubtaskComplete\` | 子目标完成音效 | 任务子目标达成。**注意：完成一个任务的最后一个目标时，游戏会同时触发本音效和"任务完成"音效（两个独立音效事件）** |
| `UISounds\DeathSting\` | 死亡提示音 | 死亡瞬间短促音效 |
| `UISounds\ErrorSound\` | 错误提示音 | 操作错误提示 |
| `UISounds\TradeSound\` | 交易完成音效 | 交易/购买完成 |

### 关于"任务完成时听到两个声音"

游戏在任务达成完成条件时会**同时**触发两个音效事件（已对 4.0.13 反编译核实）：
`QuestSubTrackComplete`（子目标完成提示音，直接播放）+ `QuestCompleted`（任务完成音乐，经通知系统播放）。
mod 对两者都是"文件夹有音乐才替换"，所以如果只给 `QuestCompleted` 放了音乐，子目标提示音仍按原版播放——这不是 bug。想完全接管：
- 两个文件夹都放音乐 = 全部替换成你的
- 只想保留自己的任务完成音乐、去掉原版提示音：往 `QuestSubtaskComplete` 文件夹放一个**静音音频文件**即可

## 环境音乐的三种模式

游戏内按 F1 打开配置 → "3. Ambient Soundtrack Settings" → "Ambient Soundtrack playlist selection"：

- **CombinedPlaylists**（默认）：`default_soundtrack` + 当前地图专属文件夹 一起参与随机
- **MapSpecificPlaylistOnly**：只用当前地图专属文件夹；该图文件夹为空时退回默认歌单
- **DefaultPlaylistOnly**：只用 `default_soundtrack`，忽略地图文件夹

## 战斗状态触发条件（combat_music）

以下任一事件会把"战斗计时器"抬到对应配置时长（可调），期间战斗音乐循环播放：

| 事件 | 默认时长 |
|---|---|
| 被子弹击中 | 20 秒 |
| 被子弹射击（子弹从身边飞过） | 12 秒 |
| 15 米内有敌人开枪 | 12 秒 |
| 20 米内手雷爆炸 | 12 秒 |
| 自己开枪 | 8 秒 |

战斗音乐淡入 4 秒、结束后淡出 8 秒（可调）；战斗期间环境音乐会压低（"战斗中环境音乐倍率"默认 0 = 静音）。

## 播放控制（点唱机快捷键）

菜单里和局内环境音乐通用（默认小键盘，F1 可改）：

| 按键 | 功能 |
|---|---|
| 小键盘 5 | 暂停 / 继续 |
| 小键盘 2 | 重播当前曲目 |
| 小键盘 4 | 上一首 |
| 小键盘 6 | 下一首（跳过） |

## 最长播放时长（"5. 时长限制设置"分组）

可给三类音乐设置最长播放时长（秒），**0 = 不限制**（默认）：

- **出生音乐**：超过设定时长时自动淡出并停止，环境音乐随之更早开始
- **死亡/撤离音乐**：结算音乐播放到设定时长自动淡出并停止
- **UI 音效**：8 种界面音效统一上限；修改即时生效（对之后触发的音效生效）

实现方式为纯播放期控制（到时淡出所在声道并停止），不改动硬盘上的原始音乐文件。主菜单音乐、环境音乐、战斗音乐不受时长限制。

> 技术备注：曾尝试"加载时在内存中截短音频"的方案，但该游戏的定制引擎（Unity 2022.3.43）上程序化创建 AudioClip 始终产出空音频，不可行，故采用播放期定时淡出。

## 音频格式与建议

- 支持扩展名：`.wav` `.ogg` `.mp3` `.mp2` `.aiff` `.s3m` `.it` `.mod` `.xm`
- 推荐 **.ogg 或 .mp3**（体积小）；追求音质用 .wav
- 文件名避免特殊符号；非音频文件（如说明 txt）会被自动忽略
- 音量平衡建议：不同来源的曲子响度差异可能较大，建议预先用音频软件标准化到统一响度
